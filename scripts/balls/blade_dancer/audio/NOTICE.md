# 女刀球刀刃音效素材声明

本目录包含一段仅供女刀球模块使用的 Ogg Vorbis 短采样：

- `blade_slice.ogg`：刀刃首次擦过敌方主球或附属单位时使用的短促擦切声。源自 Mixkit “Metallic sword scrape”（SFX 2799），按 Mixkit Sound Effects Free License 使用。制作时以项目内已按该来源裁切的工作副本为输入，再独立做约 8% 升速升调、单声道化、高低频清理、2.6 kHz 与 5.2 kHz 擦切频段增强、动态压缩、响度匹配及 0.20 秒短淡出；运行时不引用其他球目录。
